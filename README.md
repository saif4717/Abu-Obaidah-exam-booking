# نظام حجز الاختبارات القصيرة — مدرسة أبو عبيدة للبنين

واجهة عربية متجاوبة للحجز بحسب اسم المعلم والشعبة والتاريخ. يمنع حجز الشعبة نفسها مرتين في اليوم، ويستبعد الجمعة والسبت. يظهر في الواجهة الشعار الرسمي الذي أرسله المستخدم.

## رفع الملفات إلى GitHub من الهاتف

من صفحة المستودع، اضغط **uploading an existing file** في صندوق **Quick setup**، ثم اختر الملفات الثلاثة الموجودة في هذا المجلد: `index.html` و`schema.sql` و`README.md`. اكتب رسالة مثل `Add exam booking app` واضغط **Commit changes**. يجب أن يكون `index.html` في جذر المستودع حتى يعمل GitHub Pages.

## تفعيل الحجوزات المشتركة

1. أنشئ مشروع Supabase، وافتح SQL Editor، والصق محتوى `schema.sql` ثم شغّله.
2. أنشئ مستخدم الإدارة في Authentication → Users، وانسخ UUID الخاص به. ثم أضفه في SQL Editor:

   ```sql
   insert into public.exam_admins (user_id) values ('ضع-UUID-حساب-الإدارة-هنا');
   ```

3. افتح `index.html` في المستودع واختر Edit. قرب نهاية `<head>` ستجد:

   ```js
   window.APP_CONFIG = { supabaseUrl: "", supabaseAnonKey: "" };
   ```

   استبدل القيم الفارغة بعنوان مشروع Supabase ومفتاح `anon` أو `publishable`، ثم احفظ التعديل عبر **Commit changes**. لا تضع مفتاح `service_role` ولا كلمة مرور حساب الإدارة في الملف.

4. في إعدادات المستودع افتح **Settings → Pages**، واختر فرع `main` والمجلد `/ (root)`، ثم احفظ. بعد النشر استخدم رابط الموقع الذي يظهر في صفحة Pages.

من دون Supabase، يعمل الحجز محلياً للمعاينة على الجهاز نفسه فقط. بعد الربط، الحجوزات مشتركة. أسماء المعلمين والشعب المحجوزة ظاهرة لمستخدمي الموقع.
