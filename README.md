# نظام حجز الاختبارات القصيرة — مدرسة أبو عبيدة للبنين

واجهة عربية متجاوبة لحجز مواعيد الاختبارات بحسب اسم المعلم والشعبة والتاريخ. لكل شعبة تقويمها، ويمنع النظام تكرار حجز الشعبة في اليوم نفسه، مع استبعاد الجمعة والسبت.

## النشر

يوضع `index.html` و`schema.sql` في جذر مستودع GitHub، ثم يُفعّل GitHub Pages من **Settings → Pages** باختيار فرع `main` والمجلد `/ (root)`.

## إعداد Supabase

1. افتح **SQL Editor** في مشروع Supabase وشغّل محتوى `schema.sql`. يعرض الموقع الحجوزات للتقويم، بينما لا يسمح بإنشاء الحجز إلا عبر دالة تتحقق من رمز الدخول داخل قاعدة البيانات.
2. أنشئ حساب الإدارة في **Authentication → Users**، ثم أضف UUID الحساب إلى جدول `public.exam_admins` من SQL Editor:
   ```sql
   insert into public.exam_admins (user_id) values ('UUID-حساب-الإدارة');
   ```
3. في `index.html`، أضف عنوان المشروع ومفتاح `anon` أو `publishable` إلى `window.APP_CONFIG`. لا تضع مفتاح `service_role` أو كلمة مرور الإدارة في ملفات الموقع.
4. افتح الموقع، سجّل الدخول من قسم الإدارة، واضبط رمزاً من 12 إلى 64 حرفاً إنجليزياً أو رقماً. يصبح صالحاً 14 يوماً، ويمكن للإدارة تغييره قبل انتهاء المدة. لا ترسل الرمز عبر GitHub ولا تضعه في ملفات الموقع؛ شاركه مع المعلمين عبر قناة المدرسة الداخلية فقط.
5. يكتب المعلم اسمه ويختار الشعبة واليوم، ثم يدخل رمز المدرسة لتأكيد الحجز. تخزن قاعدة البيانات hash للرمز ولا تعرضه. إذا انتهت صلاحيته، تضبط الإدارة رمزاً جديداً من صفحة إدارة الحجوزات.

الرمز المشترك حل مؤقت للتحكم في الوصول، ولا يثبت هوية المعلم؛ يظل اسم المعلم مدخلاً يدوياً.
